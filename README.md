# Tomato Resizer (PNG Emotes Resizer)

It's a simple and lightweight tool designed to make resizing Emotes File process faster and easier.

The project was created to simplify repetitive image resizing tasks and is shared as a practical utility for anyone with similar needs.

Feedback and suggestions are welcome as the project continues to evolve.

## Features

- **Multiple Size Resizing**: Resize one or multiple PNG images into several custom pixel sizes in a single process.
- **Custom Pixel Sizes**: Enter the exact image sizes you need, such as `28, 56, 112`.
- **Batch Processing**: Process multiple PNG files at once instead of resizing each image individually.
- **Automatic File Naming**: Generate output files with size-based filenames for easier organization.
- **Flexible Output Folder**: Save resized images to a default `Resized` folder or choose a custom destination.
- **Multiple File Selection Methods**: Select files through a file picker or drag and drop them directly into the application.
- **Quick Access to Results**: Open the output folder immediately after the resizing process is complete.

## How to Use


### 1. Enter Your Desired Sizes

Enter the Emotes pixel sizes you want to generate.

For example:

`28, 56, 112`

### 3. Choose an Output Folder

By default, resized images are saved in a `Resized` folder within the original file's directory.

But, you can also choose a different destination through the **Folder Output Setting** option.

### 2. Select Your PNG Emotes Files

Choose your PNG Emotes images using either of the following methods:

- Click the **Drag/select file** area to browse and select one or multiple files.
- Drag and drop PNG files directly into the designated area.

### 4. Aotumatic Start the Resizing Process

Once your files and settings are selected/dragged, process will run automatically.

Tomato Resizer will generate the requested image sizes and create separate output files with size-based filenames.

### 5. Access Your Resized Files

When the process is complete, a confirmation window will appear.

From there, you can:

- Open the output folder.
- Click **OK** to end the session and return to the main window.


## Example Output

If the selected sizes are:

`28, 56, 112`

Tomato Resizer will generate separate files such as:

- `28p_emotes.png`
- `56p_emotes.png`
- `112p_emotes.png`


## Supported Format

- **Input format:** PNG
- **Platform:** Windows
- **Output:** PNG
- **Processing:** Batch resizing with custom pixel sizes


## Limitations

- Currently supports PNG files only.
- Designed for static image resizing.
- Animated image formats such as GIF are not currently supported.
- The application is currently available for Windows.
